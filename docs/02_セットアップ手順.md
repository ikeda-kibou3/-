# 02 セットアップ手順（初回だけ・30分ほど）

事務所の Windows PC で行います。

---

## 手順1 Python を入れる

1. https://www.python.org/downloads/windows/ から Python 3.11 以降をダウンロード
2. インストーラの最初の画面で **「Add python.exe to PATH」に必ずチェック**
3. 「Install Now」

確認：スタートメニュー →「cmd」→ コマンドプロンプトで

```
python --version
```

`Python 3.11.x` のように出れば成功です。

---

## 手順2 このツールを置く

このフォルダ一式を、たとえば `C:\etax-auto\` に置きます。

コマンドプロンプトで：

```
cd C:\etax-auto
python -m venv .venv
.venv\Scripts\activate
pip install -e .
playwright install chromium
```

最後の `playwright install chromium` は、自動操作用のブラウザを取ってくる命令です。
数分かかります。**これを忘れると動きません。**

---

## 手順3 関与先マスタを作る

```
copy data\clients.sample.csv data\clients.csv
```

`data\clients.csv` を Excel で開いて、関与先の情報を入れます。
中身は `docs/01_準備するもの.md` の表のとおりです。
保存するときは必ず **「CSV UTF-8（カンマ区切り）」** を選んでください。
（ただの「CSV」で保存すると法人名が文字化けします）

---

## 手順4 暗証番号を登録する

最初の1回だけ、マスターパスワードを決めます。
**これを忘れると全部登録し直しになります。** 事務所の金庫等で管理してください。

```
etax-auto cred set 1234567890123456
```

- `マスターパスワード:` → 決めたパスワードを入力
- `... の暗証番号:` → その関与先の e-Tax 暗証番号を入力（2回）

これを関与先の数だけ繰り返します。終わったら：

```
etax-auto cred verify
```

「有効な関与先すべての暗証番号が登録されています。」と出れば完了です。

---

## 手順5 チェックリストの原本を置く

スキャンした PDF 3枚を `templates\` に、決められた名前で置きます
（`docs/01_準備するもの.md` の表を参照）。

印字位置を決めます：

```
etax-auto calibrate templates\01_法人税消費税チェックリスト.pdf
```

できた `01_法人税消費税チェックリスト_座標確認.pdf` を開き、
法人名を書きたい位置の目盛りを読んで `config\checklists.yaml` に書き込みます。
3枚とも同じ要領です。

書けたら、ためしに作ってみます（e-Tax にはつながりません）：

```
etax-auto run --dry-run
```

`out\` の下にできた PDF を開いて、法人名・決算期間・担当者の位置を確認します。
ずれていたら `checklists.yaml` の数字を直して、もう一度 `--dry-run`。
**紙も e-Tax も使わずに何度でもやり直せます。**

---

## 手順6 全体の健康診断

```
etax-auto check
```

全部 `[OK]` になればセットアップ完了です。

---

## 手順7 e-Tax の画面に合わせる（初回の山場）

e-Tax の実際の画面は、このツールが想定している文言と少し違うことがあります。
まずは1社だけ、画面を見ながら流してみてください。

```
etax-auto run --only 0001
```

ブラウザが開いて自動で進みます。途中で止まって

```
【手動アシスト】'message_box' を自動で見つけられませんでした。
  ブラウザ画面で「送信結果・お知らせ」を押してください。
```

と出たら、**ブラウザ側でご自身が1回クリックして**、コマンド画面で Enter を押します。
処理はそこから続きます。初回はこれで最後まで通してください。

止まった場所は `logs\capture\` に画面のスクリーンショットとして残ります。
それを見ながら `config\selectors.yaml` を直せば、2回目からは止まらなくなります。
直し方は `docs/04_セレクタの調べ方と直し方.md` に書いてあります。

> この作業は Claude Code に任せられます。
> `logs\capture\` に溜まった画面を見せて
> 「selectors.yaml を実際の画面に合わせて直して」と頼んでください。
