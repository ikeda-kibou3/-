# 01 ご用意いただくもの

自動化の前に、いま紙とファイルに分かれている情報を **3つのファイル** にまとめます。
ここが一番大事な作業で、ここさえ揃えば毎月の作業はほぼ自動で回ります。

---

## ① 関与先マスタ（Excel／CSV 1枚）— 最重要

### まず「電子申告の達人」から出せないか確認してください

紙のファイルを開く前に、**達人の顧問先マスタからCSVで出せないか**を確かめてください。
代理送信のため、利用者識別番号は達人に登録されているはずです。
出せるなら、紙を見ながらの手入力は不要になり、書き写しの誤りも起きません。

書き出したCSVは、そのまま取り込めます（Shift_JIS のままで構いません）。

```
etax-auto import-clients "C:\達人出力\顧問先マスタ.csv"
```

列名は自動で突き合わせ、対応表を画面に出します。
2回目以降も、手で入れた延長フラグ・有効フラグ・備考は引き継がれます。

達人との役割分担は `docs/06_達人との役割分担.md`、
導入の段取りは `docs/07_残りの作業.md` を参照してください。

### 用意する表

いまキャビネット下段の

- 池田事務所：ピンクファイル「電子申告同意書綴」
- 阿部事務所：黄色ファイル「阿部事務所分電子申告ID」

に入っている情報を、次の11列の表にしてください。
`data/clients.sample.csv` がひな形です。Excelで開いて編集し、
**「CSV UTF-8（カンマ区切り）」** で `data/clients.csv` として保存します。

| 列名 | 内容 | 例 | 備考 |
|---|---|---|---|
| 関与先コード | 事務所で使っている番号 | `0001` | 出力フォルダ名になります |
| 法人名 | 正式名称 | `株式会社サンプル商事` | |
| 事務所 | 池田／阿部 | `池田` | 一覧の並び順に使います |
| 利用者識別番号 | e-Taxの16桁 | `1234567890123456` | ハイフンは入れても可 |
| 決算月 | 1〜12 | `3` | 3月決算なら `3` |
| 法人税延長 | 申告期限の延長特例 | `1`／`0` | 延長ありなら `1` |
| 消費税延長 | 同上（消費税） | `1`／`0` | |
| 消費税課税 | 課税事業者か | `1`／`0` | 免税なら `0`。消費税の通知を取りに行きません |
| 担当者 | チェックリストに書く名前 | `山田` | |
| 有効 | 処理対象にするか | `1`／`0` | 休眠・解約は `0` |
| 備考 | 自由記入 | | |

`○` `×` `有` `無` でも読み取れます。

> **暗証番号（パスワード）はこの表に書かないでください。**
> 次の②で、暗号化した別ファイルに入れます。

### 延長特例の扱い
延長の有無で「何月に処理するか」が変わります。ツールはこれを自動で振り分けます。

| 決算月 | 延長 | 申告月 | ツールが処理する月 |
|---|---|---|---|
| 3月 | なし | 5月 | **4月** |
| 3月 | 法人税のみ延長 | 法人税6月／消費税5月 | 消費税は4月、法人税は**5月** |
| 3月 | 両方延長 | 6月 | **5月** |
| 12月 | なし | 2月 | **1月** |

## ② 各社の暗証番号（画面から登録。ファイルは作りません）

紙ファイルを見ながら、1社ずつコマンドで登録します。

```
etax-auto cred set 1234567890123456
```

暗証番号の入力を求められるので入れてください（画面には表示されません）。
登録内容は `data/credentials.enc` に **暗号化されて** 保存されます。
復号にはマスターパスワードが必要で、それを知らない人にはただのバイナリです。

登録もれの確認：

```
etax-auto cred verify
```

有効な関与先のうち未登録のものが一覧で出ます。

## ③ チェックリストの原本（PDF 3枚）

いま書類ケースに入っている原本をスキャンして、次の名前で `templates/` に置いてください。
**スキャンは1回だけ**です。以後は毎月ここから自動で複製されます。

| ファイル名 | 中身 | 向き |
|---|---|---|
| `templates/01_法人税消費税チェックリスト.pdf` | ① 法人税・消費税チェックリスト | A4縦 |
| `templates/02_法人税チェックリスト.pdf` | ② 法人税チェックリスト | A4横 |
| `templates/03_消費税チェックリスト.pdf` | ③ 消費税チェックリスト | A4横 |

スキャンの設定：**白黒／300dpi／傾き補正あり**。
傾いているとそのまま印字位置がずれます。まっすぐ取り込んでください。

原本をスキャンしたら、法人名などを **どこに印字するか** を1回だけ決めます。

```
etax-auto calibrate templates/01_法人税消費税チェックリスト.pdf
```

方眼と目盛りが重なった `..._座標確認.pdf` ができます。
「法人名」欄の書き出し位置の目盛り（例：右に120、下から760）を読み取って、
`config/checklists.yaml` の `x` `y` に書きます。3枚分やれば終わりです。

## ⑤ 事前に確認していただきたいこと（2点）

### (1) 「税理士IDでまとめて取得」はできない前提で作っています

e-Tax のメッセージは、**種類によってどちらのメッセージボックスに入るかが決まって
います。**利用者が選べるものではありません。

| メッセージの種類 | 入る場所 | 税理士IDでまとめて取れるか |
|---|---|---|
| 受信通知（受付完了通知）<br>税理士が代理送信した申告の控え | 納税者と**税理士の両方** | **取れる**（送信者だから） |
| **申告のお知らせ（本ツールの対象）**<br>税務署から納税者への事前のお知らせ | **納税者のボックスのみ** | **法人は取れない** |

法人の「申告のお知らせ」は税理士のボックスに転送されません。
**関与先ごとに利用者識別番号と暗証番号でログインするのが唯一の方法**です。
いまの職員の手順は、遠回りをしているのではなく、これしかないやり方です。

委任関係の登録による「転送設定」は、**個人**納税者向けの仕組みです。
2019年1月から個人のメッセージボックス閲覧に電子証明書が原則必要になったため、
その救済として、個人の「申告のお知らせ」を税理士のボックスへ自動転送する
仕組みが用意されました。法人はこの取扱変更の対象外で、
従来どおり利用者識別番号＋暗証番号で閲覧できる代わりに、転送もされません。

このため本ツールは **1社ずつログインする方式** で作ってあります。
市販の税務ソフトの一括取得機能も、内部でやっていることは同じです。

> 出典は民間ベンダーの技術資料と税理士会系の資料で、国税庁の該当ページは
> 直接確認できていません。所轄や登録状況で違いがあり得るので、
> 一度ご自身の税理士用識別番号でログインし、関与先の「申告のお知らせ」が
> 入っていないかだけご確認いただけると確実です。
> 万一入っていれば、1回ログイン方式に作り替えます。

### (2) 自動操作についての事務所としての整理
e-Tax の画面をプログラムで操作することは、他の事務所が RPA でしているのと
技術的には同じことです。ただ、これは国税庁が公式に用意した入口ではありません。
公式には「国税電子申告・納税システムAPI」があり、そちらはソフト開発業者向けの
利用規約に基づく仕組みです。

実務上の落としどころとして、このツールは

- 1社ずつ、人がやるのと同じ速さで操作する（社と社の間に必ず間隔を空ける）
- 同時並行では動かさない
- 取得するのは自分の関与先の情報だけ

という作りにしてあります。事務所としてこの運用でよいか、
念のため一度ご確認ください。
