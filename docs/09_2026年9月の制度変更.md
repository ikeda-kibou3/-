# 09 2026年9月24日の制度変更と、この業務への影響

国税庁資料「処分通知等の電子交付の対象拡大」（令和8年9月24日〜）の要点と、
本業務（法人の「申告のお知らせ」取得）に効くかどうかの整理です。

---

## 何が変わったか

| | 変更内容 |
|---|---|
| **対象の拡大** | 電子交付を受けられる処分通知等が大幅に増えた。更正・決定通知書、<br>是認通知などを含め約1,000通知（国税庁の検索ページでは2026年10月時点で720件） |
| **同意方法** | 「申請等の都度の同意」→ **「事前の一括同意」**。<br>**従来から電子交付を使っていた人も、9月24日以後にやり直しが必要** |
| **メール** | 一括同意にはメールアドレスの登録が必須（従来は任意）。<br>通知書等が格納された旨のメールが届く |
| **税理士マイページ** | **納税者宛に電子交付された処分通知等を、税理士が閲覧できるようになった。**<br>従来の税理士マイページは通知書等の閲覧**不可**だった |
| **サブメール** | 納税者のサブメールアドレスに税理士のアドレスを登録すると、<br>**税理士にもメールが届く** |
| **例外** | 「国税還付金振込通知書」は従来どおり申告・申請等ごとの同意が必要 |
| **制限** | 国税庁資料に **「ベンダーソフトでは利用不可」** の記載あり |
| **今後** | 法人はGビズIDの活用で税目等の閲覧制限を検討中（R9.9リリース予定） |

### 代理受領と税理士マイページの違い（資料より）

| | 税理士による代理受領 | 税理士マイページ |
|---|---|---|
| 性質 | 納税者**本人に代わって受領** | 受任関係を前提に**閲覧**するだけ |
| 交付先 | 関与税理士に送信 | 納税者に送信 |
| 対象 | 税務代理権限証書で指定した税目・年分に係る通知 | 納税者に電子交付された処分通知等**すべて** |
| 前提 | 税務代理の委任＋税務代理権限証書 | e-Tax上での**受任関係の登録** |

---

## 本業務に効くか → **まだ確定できません**

### 決定的な論点

本業務でほしいのは **「法人税及び地方法人税の確定申告について」「消費税及び地方消費税の
確定申告について」= 「申告のお知らせ」** です。

**「申告のお知らせ」は「処分通知等」なのか？**

- 「処分」とは更正・決定など、課税庁が行う行政処分を指します
- 「申告のお知らせ」は**処分ではなく事前のお知らせ**です
- したがって **今回の電子交付拡大の対象外である可能性が高い**

ただし断定はできません。**国税庁の対象一覧で直接確かめられます。**

### すでに分かっていること（e-Tax のFAQより）

| 関与先 | 「申告のお知らせ」を税理士が見られるか |
|---|---|
| **個人** | 委任関係を登録すれば、税理士の「お知らせ・受信通知」に**自動転送**される |
| **法人** | **自動転送されない。** 納税者からの「メッセージ共有」が必要 |

また、「申告のお知らせ」は税理士がメールアドレスを登録していても
**税理士にはメールで通知されない**とされています。

この構図は今回の変更前から変わっておらず、今回の変更は
**処分通知等についての話**です。

### 1. 電子交付の対象一覧を引く（5分）

e-Taxホームページの **「e-Taxによる電子交付の対象となる処分通知等検索」** で、

を検索し、**本業務の2通知が対象に含まれているか**を確認してください。

### 2. 税理士マイページで1社だけ実際に見る（10分）

税理士用の電子証明書でe-Taxソフト（WEB版）にログインし、
**関与先一覧から法人1社を開いて、「お知らせ・受信通知」に
「◯◯の確定申告について」が見えるか**を確認してください。

**見えるなら、この業務の形がまるごと変わります**（下の表）。

### 3. 「ベンダーソフトでは利用不可」の範囲（販売店に確認）

国税庁資料のこの但し書きが、

- 税理士マイページ**だけ**が WEB版限定なのか
- 一括同意の手続き**だけ**が WEB版限定なのか
- それ以外にも及ぶのか

を、達人の販売店または東北税理士データ通信協同組合経由で確認してください。

## ★誤解しやすい点：マイページは「閲覧」であって「一括ダウンロード」ではありません

国税庁資料の原文にこう書かれています。

> 代理受領は、「納税者本人に代わって受領」できるものであり、
> **税理士マイページは、受任関係を前提に「閲覧」が可能となるもの**です。

**「一括でダウンロードできる」とはどこにも書かれていません。**
次の3つは別々の話なので、混ぜないでください。

| | 何の話か | マイページで変わるか |
|---|---|---|
| **① ログインの回数** | 関与先ごとに70〜80回 → 税理士の証明書で1回 | **変わる（効果大）** |
| **② 閲覧できるか** | 関与先宛の通知を税理士の画面で見られるか | **変わる可能性あり（要確認）** |
| **③ 一括ダウンロード** | 複数社分をまとめてファイルで落とせるか | **根拠なし** |

期待できるのは①と②であって、③ではありません。

### 最良の場合でも、実際の流れはこうなります

```
税理士用の電子証明書で e-Taxソフト（WEB版）にログイン ← 1回だけ
        ↓
関与先一覧から 1社目を開く → お知らせを表示 → PDF保存／印刷
        ↓
関与先一覧へ戻る → 2社目を開く → …（対象社数だけ繰り返す）
```

**「1社ずつ開く」作業は残ります。** 消えるのは、紙のファイルを引く作業と、
関与先ごとのログイン・ログアウトの繰り返しです。月6〜7社なら、
それでも手間は半分程度に減る見込みです。

### 注意すべき3つの制約

1. **電子証明書が必要**。税理士用電子証明書やマイナンバーカード等での認証が要るとされており、
   利用者識別番号＋暗証番号だけでは使えません。
2. **ベンダーソフトでは利用不可**（国税庁資料）。**達人からは使えません。**
   e-Taxソフト（WEB版）をブラウザで開く必要があります。
3. **対象は「電子交付された処分通知等」**。「申告のお知らせ」が含まれるかは未確認です。

## 確認結果によって、進め方はこう変わります

| 確認2の結果 | 取るべき道 |
|---|---|
| **税理士マイページで法人の「申告のお知らせ」が見える** | 関与先ごとのログインが不要になり、**暗証番号70〜80社分の登録も不要**になる。<br>ただし1社ずつ開く作業は残る。本ツールは**後工程専用**にできる |
| **見えない（従来どおり）** | 現行方針のまま。達人で1社ずつ落とす（方式A）か、<br>本ツールで自動ログインする（方式B） |

**確認2が最優先です。** 10分で分かります。

> なお、マイページ経由を自動化できるかは別問題です。**電子証明書でのログインは
> ICカードリーダーやPINの入力を伴うため、プログラムからの自動化が難しい**部分です。
> その場合は「人が証明書でログインし、その後をツールが引き継ぐ」形になります。

## 一括同意についての実務上の注意

一括同意は **納税者（法人）本人の手続き**です。70〜80社に同意していただく必要があります。

事務所は各社の利用者識別番号と暗証番号を預かっているため操作自体は可能ですが、
**電子交付への同意は納税者の意思表示**です。関与先への説明と了解を得たうえで
進めるかどうかは、事務所としてご判断ください。本ツールはこの手続きには関与しません。

なお、**本業務（申告のお知らせ）が電子交付の対象でないなら、この同意は本業務には
影響しません。** 確認1で対象外と分かれば、急ぐ必要はありません。
