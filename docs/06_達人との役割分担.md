# 06 「電子申告の達人」との役割分担

当事務所は NTTデータの**電子申告の達人**を導入済みです。
**このツールを使う前に、達人でどこまでできるかを確認してください。**
すでに費用を払っているものでできるなら、そちらが先です。

---

## 達人の現状（2026年8月・NTTデータ確認済み）

東北税理士データ通信協同組合の総会の場で、NTTデータの達人担当部長が
技術部門に直接確認した内容です。

| | 状況 |
|---|---|
| 個別のダウンロード | **できる** |
| **通知書の一括ダウンロード** | **未実装**（国税庁システム対応に人員を割かれていた） |
| 今後 | 2026年から要望を受けた改良に着手。本件も課題として挙げる |
| 他社 | **ミロク（MJS）は実装済み** |

したがって現時点では、**達人だけでこの作業をまとめて片付けることはできません。**

> 本ツールは、達人に一括ダウンロードが実装されるまでの橋渡しでもあります。
> 実装されたら、下の「案A」に切り替えて取得部分を捨てられるよう、
> 取得（`etax.py`）と後工程（`pdfwork.py` / `checklist.py`）は分けてあります。

---

## 達人で通知書を取得する流れ

### 仕組み（これを押さえると手順が腑に落ちます）

e-Tax のメッセージは、**利用者識別番号ごとに1つずつある「メッセージボックス」**に
入っています。これは国税庁側（クラウド）にあり、事務所のPCの中にはありません。

| 誰のボックス | 何が入るか |
|---|---|
| **関与先（法人）のボックス** | **申告のお知らせ** ← 今回ほしいのはこれ |
| 税理士のボックス | 代理送信した申告の受付完了通知 |

**「メッセージのダウンロード」とは、達人が e-Tax にログインしに行って、
ボックスの中身を事務所のPCにコピーしてくる操作**です。

ブラウザで e-Tax を開いて1社ずつ見ている現在の手順と、**やっていることは同じ**です。
違うのは、達人が利用者識別番号と暗証番号を覚えていて、取得した結果を
PC内に保存してくれる点だけです。

### 「利用者種別」が肝心です

達人は、どちらのボックスを見に行くかを **[利用者種別]** で切り替えます。

- **利用者種別：税理士** → 税理士のボックス（受付完了通知など）
- **利用者種別：納税者** → **関与先のボックス（申告のお知らせ）** ← 今回はこちら

法人の「申告のお知らせ」は税理士のボックスに転送されないため、
**必ず「納税者」を選ぶ**必要があります。達人が関与先の暗証番号を
保持しているのは、このログインに使うためです。

### 具体的な手順

> **この手順の出典について。** 達人の販売店サポート（OCC21）の記事の検索結果から
> 起こしたもので、**私は達人の画面を見ていません**（元記事そのものにも
> アクセスできませんでした）。複数の検索で同じ画面名・同じ順序が出てくるので
> 大筋は合っているはずですが、**実機で必ず確かめてください。**
> 達人のヘルプ（F1）や、OCC21の記事を事務所PCのブラウザで直接開けば確認できます。

#### A 事前設定（関与先ごとに1回だけ）

1. 電子申告の達人を起動する
2. **[送受信の設定]** をクリック
3. **[国税]** を選ぶ
4. **[受信用設定]** タブをクリック
5. **[利用者種別：納税者]** を選ぶ
6. 該当の納税者を**ダブルクリック**
7. **[取得するメッセージの対象を指定する]** にチェックを付ける
8. **[メッセージの種類]** で、ほしいもの（申告のお知らせ）にチェック
9. **[確定]**

この設定をしておかないと、すでに取得済みのメッセージが重複して
落ちてくることがある、とされています。

#### B ダウンロード（毎回）

1. **[5.メッセージ確認・納付]** を選ぶ
2. **[メッセージのダウンロード]** をクリック
3. 「受信利用者確認」画面で **[利用者種別：納税者]** を選ぶ
4. 該当の納税者の **[受信要否]** にチェックを入れる
5. **[確定]** → e-Tax に接続して取得が始まる
6. 一覧から該当のメッセージを開き、帳票を表示して印刷／PDF保存

---

## ★要確認（月曜・5分）：ここが分かれ道です

上の手順Bの **4番「受信要否のチェック」は一覧形式**です。

**この一覧で、複数の納税者に同時にチェックを入れられるでしょうか。**

| もし入れられるなら | もし1社ずつなら |
|---|---|
| **それが事実上の一括取得**です。6〜7社分を一度に落とせます | 1社ずつ繰り返すことになります |
| → **方式A** で十分。e-Taxへの自前ログイン（方式B）は不要 | → **方式B**（自前ログイン）を立ち上げる価値があります |

NTTデータの部長が「一括は未実装」とおっしゃったのが、

- この一覧そのものが無い（1社ずつしか選べない）という意味なのか
- 選べはするが、**取得後の帳票を一括でPDF/印刷できない**という意味なのか
- ミロクのような**ワンクリックの機能が無い**という意味なのか

で、作るべきものが変わります。**実際の画面を見れば5分で判明します。**

あわせて確認いただきたいこと:

- [ ] 手順Bの4で、複数の納税者にチェックを入れられるか
- [ ] 落とした「申告のお知らせ」を**PDFとして保存**できるか（印刷だけか）
- [ ] PDFで保存できる場合、**保存先フォルダとファイル名**はどうなるか
- [ ] 事前設定Aの[メッセージの種類]に「申告のお知らせ」系の項目があるか

3つめが分かれば、方式A（`--from-dir`）の突き合わせを実物に合わせられます。

## 達人では埋まらないところ

達人がやってくれるのは**ダウンロードまで**です（しかも今は1社ずつ）。
手順書の作業時間の半分以上は、実はその後にあります。

| 工程 | 達人 | このツール |
|---|---|---|
| 決算期が到来した関与先を選ぶ（申告期限延長・免税事業者を考慮） | × | ○ |
| e-Taxから2種類のお知らせを取得 | △（1社ずつ） | ○（全社を通しで） |
| 消費税は2枚のうち1ページ目だけにする | × | ○ |
| 税額に蛍光ペン（黄色ハイライト） | × | ○ |
| チェックリスト3枚に法人名・決算期間・担当者を印字 | × | ○ |
| ①②③(a)(b) の順に1本へ束ねる | × | ○ |
| 全社の成否を一覧で残す | × | ○ |

## 3つの進め方

### 案A 達人で落として、後工程だけこのツール（実装済み）

達人（または手作業）で保存したPDFを1つのフォルダに集め、こう実行します。

```
etax-auto run --from-dir "C:\達人出力\2026-04"
```

e-Tax へ自前でログインしないので、**画面変更で壊れるリスクが消えます。**

ファイル名も出力形式も決め打ちしていません。ファイル名と本文の両方を見て、
**利用者識別番号 → 法人名の固有部分 → 関与先コード** の順に関与先を突き合わせ、
税目は `settings.toml` の `[notices]` のパターンで判定します。
関係のないPDFが混ざっていても拾いません。

達人に一括ダウンロードが実装されたら、**この案Aがそのまま使えます。**
いま（個別ダウンロードのみ）でも、落としたファイルをフォルダに集めれば使えます。

### 案B このツールだけで通す（現在の既定）

取得から束ねまで一気通貫で行います。達人に一括ダウンロードが無い現状では、
**全社をまとめて片付けられるのはこの案だけ**です。

```
etax-auto run
```

### 案C いまのまま手作業を続ける

法人70〜80社なら、決算期が来るのは月平均6〜7社です。
1社7分として月45分、チェックリストの作成を合わせて**月1時間半、年18時間**ほど。
この数字だけを見れば、仕組みを作って保守する手間と釣り合うかは微妙です。

それでも自動化する価値があるとすれば、時間よりも次の点です。

- **手順が文書とコードとして残る**（担当者が替わっても引き継げる）
- **漏れと取り違えが起きない**（対象の抽出を人の記憶に頼らない）
- **やった／やっていないが記録に残る**（`_結果一覧.csv`）

## 個人の関与先（100件近く）について

**個人は法人と扱いが違います。**

2019年1月以降、個人のメッセージボックス閲覧には電子証明書が原則必要になり、
その代わりに**委任関係を登録すれば、個人の「申告のお知らせ」が
税理士のメッセージボックスへ自動転送される**仕組みが用意されました。

つまり **個人はまとめて取得できます。** 法人のように1社ずつログインする必要はありません。

確定申告期（1〜3月）に100件近くを扱うのであれば、
- 全件について委任関係の登録が済んでいるか
- 達人の「所得税確定申告のお知らせ」の取得設定が入っているか

を確認する価値があります。こちらは法人の月次より効果が大きいかもしれません。
ただし**このツールは法人の月次ルーチン専用**で、個人には対応していません。
