# 06 「電子申告の達人」との役割分担

当事務所は NTTデータの**電子申告の達人**を導入済みです。
**このツールを使う前に、達人でどこまでできるかを確認してください。**
すでに費用を払っているものでできるなら、そちらが先です。

---

## 達人にできること（要確認）

達人にはメッセージボックスからメッセージをダウンロードする機能があり、
**顧問先のメッセージボックスにのみ格納される「申告に関するお知らせ」**も
対象に含まれると案内されています。

仕組みは当ツールと同じで、**顧問先の利用者識別番号でログインして取得**します。
法人の「申告のお知らせ」は税理士のボックスに転送されないため、
どのソフトを使ってもここは変わりません。

関係する設定として、顧問先ごとの **「受信要否」のチェック** があります。
これを入れた顧問先の「受付完了通知」や「お知らせ」がダウンロード対象になります。

### 連休明けに職員へ確認してもらうこと

- [ ] 達人の顧問先マスタに、**利用者識別番号**が登録されているか
- [ ] 達人の顧問先マスタに、**暗証番号**も登録されているか
      （代理送信は税理士の電子証明書で行うため、未登録の事務所も多い）
- [ ] 顧問先マスタを **CSVでエクスポート**できるか
- [ ] **メッセージの一括ダウンロード**機能があるか。あればどのメニューか
- [ ] 「受信要否」の設定が全顧問先で入っているか
- [ ] **法人の「申告のお知らせ」**が実際に落ちてくるか（1社で試す）

上の確認がすべて取れれば、**このツールの「e-Taxから取得する部分」は不要**になります。

---

## 達人では埋まらないところ

達人がやってくれるのは**ダウンロードまで**です。
手順書の作業時間の半分以上は、実はその後にあります。

| 工程 | 達人 | このツール |
|---|---|---|
| 決算期が到来した関与先を選ぶ（申告期限延長・免税事業者を考慮） | × | ○ |
| e-Taxから2種類のお知らせを取得 | **○（要確認）** | ○ |
| 消費税は2枚のうち1ページ目だけにする | × | ○ |
| 税額に蛍光ペン（黄色ハイライト） | × | ○ |
| チェックリスト3枚に法人名・決算期間・担当者を印字 | × | ○ |
| ①②③(a)(b) の順に1本へ束ねる | × | ○ |
| 全社の成否を一覧で残す | × | ○ |

## 3つの進め方

### 案A 達人＋このツールの後工程（推奨・達人で取得できる場合）

1. 達人でメッセージを一括ダウンロード
2. 取得したファイルをこのツールに渡し、ページ抽出・ハイライト・
   チェックリスト作成・束ねを行う

e-Taxへ自前でログインしなくなるため、**画面変更で壊れるリスクが消えます。**
この形にする場合は `src/etax_auto/etax.py` を使わず、
達人の出力フォルダを読む入口を追加します（未実装）。

### 案B このツールだけで通す（達人で取得できない場合）

現在の実装のとおり、取得から束ねまで一気通貫で行います。

### 案C いまのまま手作業を続ける

法人70〜80社なら、決算期が来るのは月平均6〜7社です。
1社7分として月45分、チェックリストの作成を合わせて**月1時間半、年18時間**ほど。
この数字だけを見れば、仕組みを作って保守する手間と釣り合うかは微妙です。

それでも自動化する価値があるとすれば、時間よりも次の点です。

- **手順が文書とコードとして残る**（担当者が替わっても引き継げる）
- **漏れと取り違えが起きない**（対象の抽出を人の記憶に頼らない）
- **やった／やっていないが記録に残る**（`_結果一覧.csv`）

## 個人の関与先（100件近く）について

**個人は法人と扱いが違います。**

2019年1月以降、個人のメッセージボックス閲覧には電子証明書が原則必要になり、
その代わりに**委任関係を登録すれば、個人の「申告のお知らせ」が
税理士のメッセージボックスへ自動転送される**仕組みが用意されました。

つまり **個人はまとめて取得できます。** 法人のように1社ずつログインする必要はありません。

確定申告期（1〜3月）に100件近くを扱うのであれば、
- 全件について委任関係の登録が済んでいるか
- 達人の「所得税確定申告のお知らせ」の取得設定が入っているか

を確認する価値があります。こちらは法人の月次より効果が大きいかもしれません。
ただし**このツールは法人の月次ルーチン専用**で、個人には対応していません。
