# 08 事務所PCへの導入（Claude は要りません）

## 大前提：Claude は事務所PCに不要です

ここを誤解されやすいので、最初にはっきりさせます。

| | 使うもの | 置き場所 |
|---|---|---|
| **毎月の処理を動かす** | Python と etax-auto 一式 | **事務所PC** |
| **仕組みを作る・直す** | Claude Code | **どのPCでも**（自宅・外出先で可） |

**Claude Code は「作る道具」であって「動かす道具」ではありません。**
できあがったプログラムは普通の Python のプログラムなので、
毎月の実行に Claude も、インターネット越しのAIも、一切関係しません。

事務所PCから外に出ていく通信は、**e-Tax（方式Bの場合）だけ**です。
方式A（達人で落としたPDFを取り込む）なら、**外部通信はゼロ**です。

---

## 事務所PCに置くもの

```
C:\etax-auto\
    初回セットアップ.bat        ← 最初に1回だけダブルクリック
    毎月の実行_方式A.bat        ← 毎月これ（PDFのフォルダをドラッグ＆ドロップ）
    毎月の実行_方式B.bat        ← 方式Bを使う場合
    src\  config\  docs\  data\  templates\  out\
```

職員さんが打つコマンドは **ありません。** バッチをダブルクリックするだけです。

## 持ち込み方

### 方法1 GitHub から ZIP（おすすめ・USB不要）

事務所PCのブラウザで、このリポジトリの
`claude/admiring-davinci-i90i44` ブランチを開き、
**Code → Download ZIP** で一式を落とします。
`C:\etax-auto\` に展開してください。Git は要りません。

更新したいときも、同じ手順で新しい ZIP を展開するだけです。
ただし **`data\` と `templates\` は上書きしないでください**（関与先マスタと様式が消えます）。

### 方法2 USBメモリ

外に出せない事務所PCの場合。ZIP を USB で運びます。
**`data\clients.csv` を入れた USB は事務所から持ち出さないでください。**

## セットアップ（1回だけ・15分）

1. Python 3.11 以降を入れる
   - https://www.python.org/downloads/windows/
   - インストーラ最初の画面で **「Add python.exe to PATH」に必ずチェック**
2. `初回セットアップ.bat` をダブルクリック
   - 必要な部品を自動で入れ、最後に設定の検査結果を出します
   - 途中で「方式Bも使いますか？」と聞かれます。当面は `n` で構いません

Python が見つからない場合は、その旨と入れ方がバッチに表示されます。

## Python を入れられない場合

事務所PCに管理者権限が無い、ソフトの導入が禁止されている、という場合です。

### 案ア ポータブル版 Python（インストール不要）

Python には「展開して置くだけ」の配布形式があります。
レジストリも PATH もいじらないので、管理者権限が要りません。

1. https://www.python.org/downloads/windows/ から
   **Windows embeddable package (64-bit)** をダウンロード
2. `C:\etax-auto\python\` に展開
3. `python\python311._pth` をメモ帳で開き、`#import site` の **先頭の # を外して**保存
4. https://bootstrap.pypa.io/get-pip.py を `C:\etax-auto\` に保存
5. コマンドプロンプトで

```
cd C:\etax-auto
python\python.exe get-pip.py
python\python.exe -m pip install -r requirements-minimal.txt
```

以後は `python\python.exe -m etax_auto ...` で動きます。

> この手順は Windows 実機で検証していません。手間取るようなら案イへ。

### 案イ 先生のPCで動かす

**方式Aなら、処理するのはPDFの加工だけ**なので、事務所PCである必要がありません。
達人で落としたPDFを共有フォルダに置き、先生のPCで実行して、
できた `_束ね.pdf` を共有フォルダに戻す、という形でも回ります。

ただし**関与先の税額が入ったPDFがPC間を移動する**ので、
事務所内の共有フォルダに限り、外部クラウドは経由しないでください。

### 案ウ ベンダーに頼む

データ通信協同組合や導入ベンダーに、Python の導入だけ依頼する方法です。
「Python 3.11 を入れて PATH を通すだけ」で、ソフトの新規導入というより
開発環境の整備に当たるので、話は通りやすいはずです。

## 保守はどこでやるか

事務所PCに Claude が無くても困りません。直す作業は先生の手元で完結します。

| 直したいこと | どこで | やり方 |
|---|---|---|
| 関与先の追加・変更 | **事務所PC** | `data\clients.csv` を Excel で編集。Claude 不要 |
| チェックリストの印字位置 | **事務所PC** | `config\checklists.yaml` の数字を直す。Claude 不要 |
| 対象月の判定を変えたい | 先生のPC | Claude Code で直して、ZIP を入れ替え |
| e-Tax の画面が変わった（方式B） | 先生のPC | `logs\capture\` を持ち帰り、Claude Code で `selectors.yaml` を直す |
| 達人の出力形式が変わった | 先生のPC | 同上。`intake.py` の突き合わせを調整 |

**日常の変更（関与先の増減、印字位置）はすべて事務所PCだけで完結します。**
Claude が要るのは、仕組みそのものを変えるときだけです。
その頻度は年に数回あるかないかで、そのときは ZIP を入れ替えれば済みます。

## 事務所PCに残る情報

| ファイル | 中身 | 扱い |
|---|---|---|
| `data\clients.csv` | 法人名・利用者識別番号・決算期 | 持ち出さない |
| `data\credentials.enc` | 暗号化した暗証番号（**方式Bのみ**） | 持ち出さない |
| `out\` | 関与先の税額が入ったPDF | 文書管理規程に従って整理 |
| `logs\` | 実行ログ。方式Bでは画面の写真も | 法人名が写るので持ち出さない |

**方式Aなら `credentials.enc` は作られません。** 暗証番号は達人の中だけにあります。
