# 07 残りの作業（チェックリスト）

達人の電子申告アプリに**利用者識別番号と暗証番号の両方**が登録済みであることが
確認できました。ここからの段取りです。

---

## その前に：方式を決めます

暗証番号が達人に入っているので、**選べる道が2つ**になりました。

### 案A 達人で落として、後工程をこのツール（おすすめ）

```
達人で個別ダウンロード（6〜7社）→ 1つのフォルダに集める
        ↓
etax-auto run --from-dir "C:\達人出力\2026-04"
        ↓
関与先ごとの _束ね.pdf → 片面印刷
```

| 良い点 | |
|---|---|
| **暗証番号を二重に持たない** | 達人1か所で管理。当ツールに登録する作業が丸ごと不要 |
| **e-Taxの画面変更で壊れない** | 自前でログインしないため |
| **達人が一括DLを実装したら、そのまま移行できる** | コマンドは変わりません |
| 準備が軽い | Python のブラウザ部品（playwright）が不要 |

| 弱い点 | |
|---|---|
| ダウンロードは1社ずつ手作業 | 達人に一括DLが無いため（月6〜7社） |

### 案B このツールだけで通す

```
etax-auto run   → ログインから束ねまで全自動
```

| 良い点 | 弱い点 |
|---|---|
| 全社まとめて完全に自動 | **暗証番号を当ツールにも登録**（70〜80社、二重管理） |
| | e-Taxの画面が変わると止まる（手動アシストで続行は可能） |
| | 初回にセレクタの調整が要る |

### 判断の目安

**まず案Aで始めることをおすすめします。** 準備が軽く、二重管理も画面変更のリスクも
背負わずに、作業時間の半分以上を占める後工程（ページ抽出・ハイライト・
チェックリスト・束ね）をすぐ自動化できます。

達人の一括DLが実装されない、あるいは個別ダウンロードが思ったより手間、
となった時点で案Bに足せば十分です。**どちらも同じ後工程を使うので、
案Aで始めた作業は無駄になりません。**

---

## 作業1 達人から顧問先マスタをCSVで書き出す（職員・30分）

達人の顧問先マスタをCSVでエクスポートします。列は多くて構いません。
必要なのは次の5つで、あれば拾います。

法人名 / 顧問先コード / 利用者識別番号 / 決算月（または事業年度終了日）/ 担当者

**暗証番号は書き出さないでください。** 当ツールは使いませんし、
平文のCSVに並べた時点でそれが事務所で一番危険なファイルになります。

## 作業2 関与先マスタに変換する（5分）

```
etax-auto import-clients "C:\達人出力\顧問先マスタ.csv"
```

Shift_JIS のままで読めます。列名は自動で突き合わせ、**対応表を画面に出します。**
当たらなかった列があれば `config/import_map.yaml` に1行足して、もう一度実行してください。

2回目以降の取り込みでも、**手で入れた延長フラグ・有効フラグ・備考は引き継がれます。**
関与先が増えたら、このコマンドを流し直すだけで済みます。

## 作業3 人でしか判断できない4項目を埋める（1〜2時間）

`data/clients.csv` を Excel で開いて確認します。達人から取れない項目です。

| 列 | 入れ方 | 重要度 |
|---|---|---|
| **法人税延長** | 申告期限の延長特例あり → `1` | **最重要** |
| **消費税延長** | 同上（消費税） | **最重要** |
| 消費税課税 | 免税事業者 → `0` | 中 |
| 有効 | 休眠・解約 → `0` | 中 |

**延長フラグを間違えると、その関与先が処理される月がまるごとずれます。**
70〜80社で一番気を使うのはここです。逆にここさえ正しければ、あとは機械が拾います。

保存は必ず「**CSV UTF-8（カンマ区切り）**」で。

## 作業4 検査する（5分）

```
etax-auto check
```

利用者識別番号が16桁か、コードや識別番号が重複していないかを全件調べます。
達人からの取り込みなら誤りは出にくいはずですが、念のため。

続けて、抽出が合っているかを月ごとに見ます。

```
etax-auto plan --date 2026-04-15
etax-auto plan --date 2026-05-15
```

**1年分（12か月）を一通り確認してください。** 全社がどこか1つの月に現れるはずです。
どこにも出てこない関与先があれば、決算月か有効フラグが誤っています。

## 作業5 チェックリストの原本を用意する（1時間）

1. 紙の原本3枚をスキャン（**白黒 / 300dpi / 傾き補正あり**）して `templates/` へ
   - `01_法人税消費税チェックリスト.pdf`（A4縦）
   - `02_法人税チェックリスト.pdf`（A4横）
   - `03_消費税チェックリスト.pdf`（A4横）
2. 印字位置を決める

```
etax-auto calibrate templates\01_法人税消費税チェックリスト.pdf
```

方眼入りのPDFができるので、目盛りを読んで `config\checklists.yaml` の `x` `y` を直します。

3. 位置を確かめる

```
etax-auto run --dry-run
```

`out\` にできたPDFを開いて、法人名・決算期間・担当者の位置を見ます。
ずれていたら数字を直してもう一度。**紙も e-Tax も使わずに何度でもやり直せます。**

## 作業6 達人の出力を1社分だけ確認する（10分）

e-Tax が開けるようになったら、**1社だけ**達人で個別ダウンロードして、
保存先のフォルダとファイル名を確認してください。そのうえで：

```
etax-auto run --only 0001 --from-dir "C:\達人出力\2026-04"
```

`_結果一覧.csv` の「法人税通知」「消費税通知」が **「取得」** になれば成功です。
**「該当なし」** なら、ファイル名と本文から関与先を特定できていません。
その1社分のファイル名と先頭数行（法人名と税額は伏せて構いません）を見せていただければ、
突き合わせの条件を合わせます。

## 作業7 本番（毎月15日頃）

```
達人で当月分をダウンロード → フォルダに集める
etax-auto plan                    ← 対象を目で確認
etax-auto run --from-dir <フォルダ>
_束ね.pdf を片面印刷
```

---

## 案Bも使う場合に追加で必要なこと

- `playwright install chromium`（初回のみ）
- 暗証番号を当ツールにも登録（`etax-auto cred set <識別番号>` を70〜80回）
- 初回1社で `etax-auto run --only 0001` を画面を見ながら流し、
  止まったところの `config\selectors.yaml` を直す（`docs/04`）

| 5 チェックリストの原本 | 1時間 | 職員 |

| **合計** | **半日弱** | |

案Bを足す場合は、暗証番号の登録とセレクタ調整でさらに半日ほど見てください。
