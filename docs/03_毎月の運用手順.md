# 03 毎月の運用手順

セットアップが済んだあとの、**毎月15日頃の作業**です。

---

## いまの手順との対応

| | いままで | これから |
|---|---|---|
| 1 | Outlook にお知らせメールが届く | 同じ（きっかけは変わりません） |
| 2 | 紙ファイルで識別No.とパスワードを探す | **不要**（マスタに入っています） |
| 3 | 1社ずつログイン → メッセージボックス → 2枚印刷 → ログアウト | **`etax-auto run` 1回** |
| 4 | 消費税は2枚のうち1ページ目だけ選んで印刷 | **自動**（設定で指定済み） |
| 5 | 税額に蛍光ペンでライン | **自動**（黄色ハイライト付きで出力） |
| 6 | チェックリスト3枚をコピーして手書き | **自動**（法人名・決算期間・担当者を印字） |
| 7 | ①②③(a)(b) の順に並べてクリップ止め | **自動**（`_束ね.pdf` 1本にまとまっています） |
| 8 | クリアファイルに入れてキャビネットへ | 同じ（人の作業） |

---

## 手順

### ステップ1 今月の対象を確かめる（30秒）

```
cd C:\etax-auto
.venv\Scripts\activate
etax-auto plan
```

```
【2026年05月申告分】対象 7 社（実行日 2026年04月15日）
--------------------------------------------------------------------------
コード  事務所  法人名                        決算期末    法人税  消費税  担当
--------------------------------------------------------------------------
0001    池田    株式会社サンプル商事          2026/03     ○      ○      山田
...
```

**ここで必ず目を通してください。**
思っていた会社が入っていない／余計な会社が入っているときは、
`data\clients.csv` の決算月・延長・有効フラグを直します。
このツールが間違えるとしたら、ほとんどがマスタの入力ミスです。

### ステップ2 実行する（7社で15分ほど）

```
etax-auto run
```

ブラウザが開いて、1社ずつ自動で進みます。
**画面は見ていなくて構いませんが、PCは触らないでください。**
（自動操作中にウィンドウを切り替えると失敗することがあります）

終わると結果が出ます：

```
==========================================================
 処理結果  2026年04月15日 10:32
   対象 7 社 / 完了 6 社 / 要確認 1 社

 【手作業で確認が必要な関与先】
   ・有限会社テスト製作所（佐藤） 該当のお知らせがありません
==========================================================
```

### ステップ3 出力を確認して印刷する

`out\2026-05申告分\` の下に、関与先ごとのフォルダができています。

```
out\2026-05申告分\
  0001_株式会社サンプル商事\
      01_法人税消費税チェックリスト.pdf   ← 法人名・担当者を印字済み
      02_法人税チェックリスト.pdf
      03_消費税チェックリスト.pdf
      a_法人税通知.pdf                    ← 1ページ・税額に黄色ライン
      b_消費税通知.pdf                    ← 1ページ目のみ
      _束ね.pdf                           ★これ1本を片面印刷すれば完成
  _結果一覧.csv
```

**`_束ね.pdf` を開いて片面印刷** すれば、①②③(a)(b) の順に出てきます。
あとはクリップ止めしてクリアファイルへ入れるだけです。

複数社をまとめて印刷したいときは、各フォルダの `_束ね.pdf` を選んで
右クリック →「印刷」でまとめて流せます。

### ステップ4 「要確認」の関与先だけ手作業

`_結果一覧.csv` の「メモ」欄に理由が書いてあります。よくあるのは：

| メモ | 意味 | 対応 |
|---|---|---|
| 該当なし | まだお知らせが届いていない | 数日おいて `etax-auto run --only 0002` |
| ログインに失敗 | 暗証番号が変わった | `etax-auto cred set <識別番号>` で入れ直す |
| 原本なし | チェックリストPDFが無い | `templates\` を確認 |
| 画面が見つかりません | e-Taxの画面が変わった | `docs/04` を見て `selectors.yaml` を直す |

## よく使うコマンド

```
etax-auto plan                     今月の対象を見るだけ
etax-auto plan --date 2026-07-15   7月に実行したら誰が対象かを先に見る
etax-auto run                      本番
etax-auto run --only 0002 0005     特定の関与先だけやり直す
etax-auto run --dry-run            e-Taxにつながず、チェックリストだけ作る
etax-auto run --from-dir <フォルダ> e-Taxにつながず、達人などで落としたPDFを取り込む
etax-auto cred verify              暗証番号の登録もれを確認
etax-auto check                    調子が悪いときの健康診断
```

## Claude Code に頼む場合

このフォルダで Claude Code を起動して、日本語で頼めます。

- 「今月の対象を見せて」
- 「0002 だけやり直して」
- 「先月分で失敗した会社を教えて」
- 「新しい関与先を1社マスタに追加して」
- 「e-Taxの画面が変わったみたいなので直して」（`logs\capture\` の画像を見せてください）

`.claude/skills/etax-monthly/` に毎月の段取りを書いてあるので、
Claude Code は手順を覚えていなくても同じ順番で動きます。
