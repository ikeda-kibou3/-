# チェックリストの原本を置く場所

書類ケースにある紙の原本をスキャンして、次の名前でこのフォルダに置いてください。

| ファイル名 | 中身 | 向き |
|---|---|---|
| `01_法人税消費税チェックリスト.pdf` | ① 法人税・消費税チェックリスト | A4縦 |
| `02_法人税チェックリスト.pdf` | ② 法人税チェックリスト | A4横 |
| `03_消費税チェックリスト.pdf` | ③ 消費税チェックリスト | A4横 |

スキャン設定：**白黒 / 300dpi / 傾き補正あり**。
傾いたまま取り込むと、そのぶん印字位置がずれます。

置いたら、印字位置を決めます：

```
etax-auto calibrate templates/01_法人税消費税チェックリスト.pdf
```

方眼入りの `_座標確認.pdf` ができるので、目盛りを読んで
`config/checklists.yaml` の `x` `y` に書き込んでください。

※ スキャンしたPDFは事務所の様式なので `.gitignore` で除外しています。
